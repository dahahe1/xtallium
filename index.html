Common Formulas Reference Sheet
  • Slope: m = (y2 - y1) / (x2 - x1)
  • Slope-intercept form: y = mx + b
  • Standard form: Ax + By = C
  • Point-slope form: y - y1 = m(x - x1)
  • Distance formula: d = sqrt((x2 - x1)^2 + (y2 - y1)^2)
